# PRAYOG Maharashtra

Static prototype (HTML/CSS/JS, no build). 
Run: open `index.html`, or `python3 -m http.server 8000` and visit http://localhost:8000

```
index.html
css/style.css
js/app.js
```

## Added
- `js/ext.js`: student ratings, citizen rating after resolution, lead-conflict rule (higher-rated student preferred), leaderboard, alerts page, university/citizen-first navigation.
